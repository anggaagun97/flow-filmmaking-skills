# Earshot dan audio

Baca skill `earshot` sebelum memilih, membandingkan atau menilai bunyi. Verifikasi runtime dengan doctor bila instalasinya belum diketahui. Skill terpasang tidak membuktikan model dan paket audio siap. Jika runtime belum tersedia, laporkan blocker penilaian audio dan jangan mengklaim sudah mendengarkan.

Pakai MCP Earshot yang mempertahankan model di memori atau satu proses Python untuk beberapa analisis. CLI terpisah dapat memuat model selama puluhan detik setiap panggilan. Analisis segmen yang berubah atau kandidat yang masuk shortlist; gunakan cache untuk file yang sama.

Gunakan rank/match untuk pilihan musik/SFX, describe/timeline untuk kejadian dan timing, measure untuk loudness serta clipping, compare/ab untuk revisi mix. Pilih fungsi sesuai pertanyaan, bukan menjalankan semua pemeriksaan pada setiap file. Catat angka dan batas interpretasi yang diminta skill Earshot. Transkrip dan waveform saja belum cukup untuk menilai karakter suara.

Selaraskan cue dengan ID shot dan waktu timeline. Periksa file audio yang benar-benar dipakai, lalu mix final terhadap gambar. Jika pengguna meminta hasil hening, verifikasi tidak ada audio tak diinginkan. Simpan sumber, lisensi, trim, gain dan path mix agar edit manual dapat diulang. Jangan menambahkan musik/narasi/subtitle otomatis di luar brief.
